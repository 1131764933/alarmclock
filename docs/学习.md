
升级成一个真正可复用的工程学习框架。以后你拿到任何项目（Web3 / Rust / 量化 / 后端）都可以按这个走。
我把它叫做：
🧠 工程项目学习框架（7步法）
1 运行项目
2 建立地图
3 追踪数据
4 修改代码
5 重写功能
6 重构系统
7 输出知识
核心思想只有一句话：
先运行 → 再理解 → 再修改 → 再重写
而不是一上来读代码。

① 运行项目（Run）
目标：让项目活起来
做4件事：
1 安装依赖
例如
cargo build
npm install
pip install -r requirements.txt

2 跑测试
cargo test
npm test
pytest
测试通过说明：
环境 OK
依赖 OK
代码 OK

3 构建产物
cargo build
cargo wasm
npm run build
观察输出：

4 运行 Demo
例如
cargo run
docker compose up
npm start
只回答一个问题：
这个项目是干什么的

② 建立地图（Map）
目标：理解项目结构
画目录：

 │   ├─ state
 │   └─ tests
 ├─ config
 ├─ docs
 └─ build

这样你脑子里就有 项目地图。
